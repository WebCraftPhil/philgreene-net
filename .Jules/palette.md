## 2025-05-20 - Multi-card repeated button text and copy button interaction feedback
**Learning:** In card grid layouts (like pricing or package selections), repeating generic button labels ("Ask about this package") without package identifiers confuses screen reader users navigating by buttons or rotor. Providing WCAG 2.5.3 compliant `aria-label` starting with the visible label text gives crucial context while maintaining visual design. Furthermore, clipboard action buttons require immediate, local visual feedback on the button element itself alongside status region announcements.
**Action:** Always include specific package context in `aria-label` on repeated card CTA buttons, and provide temporary button feedback state (e.g. icon and text shift) when a user triggers copy actions.
